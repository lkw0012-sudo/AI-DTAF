# DTAF AI Pipeline Guideline Documents

These documents explain the Digital Twin Analytical Framework, the supporting frameworks used by the DTAF AI Pipeline, the installation process, the required user inputs, and the interpretation of the pipeline's generated results.

## Available Documents

**[Document 0: Executive Summary](00-executive-summary.pdf)**  
   Provides a concise overview of the DTAF AI Pipeline, its purpose, and its intended use.

**[Document 1: Introduction to the DTAF AI Pipeline](01-introduction-to-dtaf-ai-pipeline.pdf)**  
   Introduces DTAF and explains how the pipeline's supporting frameworks work together.

**[Document 2: Quick-Start Installation Guide](02-quick-start-installation-guide.pdf)**  
   Describes the hardware and software requirements and explains how to install and run the pipeline.

**[Document 3: CNC Case Study](03-cnc-case-study.pdf)**  
   Demonstrates how the DTAF AI Pipeline can be applied to a manufacturing use case.
  
**[Document 4: DEMA CNC Case Study](04-dema-cnc-case-study.pdf)**  
   Demonstrates how DEMA can be applied to a manufacturing use case.

**[Document 5: DTAF AI Pipeline Quick Demo](05-quick-demo.pdf)**  
   Provides a concise demonstration of the pipeline workflow and generated results.

**[Document 6: Supporting Materials](06-supporting-materials.pdf)**  
   Contains supplementary information and supporting resources for the DTAF AI Pipeline.

## Recommended Reading Order

New users should review the documents in numerical order.

Users who are ready to install the pipeline may proceed directly to **Document 2: Quick-Start Installation Guide**. Users interested in a practical manufacturing example may proceed to **Document 3: CNC Case Study**.
